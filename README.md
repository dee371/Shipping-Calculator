# Shipping Calculator

Shipping Calculator is a simple web-based project that helps users calculate the estimated cost of shipping a parcel.

## Features

- Enter pickup location
- Enter delivery location
- Enter package weight
- Select package type
- Select delivery speed
- Calculate estimated shipping cost
- Display estimated delivery time

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` – Website structure
- `style.css` – Website design
- `script.js` – Shipping calculation logic
- `README.md` – Project information

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Enter the required details.
4. Click **Calculate Shipping**.
